# SHIFT layered product scene — demo asset record

Generated for the unpublished SHIFT dev-shop review theme. These are demonstration assets and should be replaced or re-approved when the real assortment is selected.

## Files and use

- `assets/shift-layered-desk-background.png` — product-free warm oak desktop and cream wall background.
- `assets/shift-layered-little-horizon.png` — transparent cutout for The Little Horizon.
- `assets/shift-layered-pebble-pause.png` — transparent cutout for The Pebble Pause.
- `assets/shift-layered-cloud-rest.png` — transparent cutout for The Cloud Rest.

## Generation constraints

Each product cutout was generated from its existing primary product image. The prompt required the same silhouette, color, material, proportions, and visible function; a transparent background; a restrained contact shadow; and no text, watermark, added parts, or invented features. The desk background was generated separately without products so the section can layer the transparent assets responsively.

The section settings allow each cutout and the background to be replaced in the theme editor. If a product slot is empty, its visual layer and shopping entry are both omitted.
